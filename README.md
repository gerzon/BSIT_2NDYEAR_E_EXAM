# BSIT 2nd Year E-Exam

A short quiz webpage for BSIT 2nd Year programming fundamentals and Java basics.

## Project Overview

This project is a single-page exam/quiz interface built with HTML, CSS, and JavaScript. It includes:

- Multiple-choice questions
- Essay questions
- Print and screenshot deterrence behavior
- Mobile-friendly responsive layout

## Files

- `index.html` – main quiz page

## Run Locally

Open the file directly in a browser:

```bash
index.html
```

Or use a local web server if preferred:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
